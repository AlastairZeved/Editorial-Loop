# Schema: Flow Weld

## Recognition Trigger
Any edit has been made — a word changed, a sentence rewritten, a paragraph restructured, a section moved. The edit exists. Now check whether it broke anything.

## Execution Sequence

**READ UP:** Read the full paragraph (or section) BEFORE the edit. Read it as if the edit doesn't exist yet. Note:
- What tone is established?
- What concept is the reader holding?
- What direction is the text moving?
- What does the reader expect to encounter next?

**READ THE EDIT:** Now read the edited text. Ask:
- Does it arrive where the preceding context was pointing?
- Or does the reader experience a seam — a shift in tone, concept, direction, or register?
- Would a reader coming from the paragraph above land here naturally, or would they stumble?

If stumble → the weld between "before" and "edit" is broken. Mark it.

**READ DOWN:** Read the full paragraph (or section) AFTER the edit. Ask:
- Does the edited text set up what follows?
- Or does the reader experience a second seam — the text after the edit no longer connects to what's above it?
- Could someone read edit → after as continuous thought?

If seam → the weld between "edit" and "after" is broken. Mark it.

**REPAIR:** For each broken weld:
1. Identify which side of the weld is broken (before→edit, edit→after, or both)
2. Identify WHAT broke: tone shift? concept jump? register change? direction reversal?
3. Rewrite the broken segment. Not the edit alone — whichever of the three (before, edit, after) needs to change to restore continuous flow.
4. After rewriting, re-enter READ UP for the new text.

## Scale
- **Sentence level:** Primary scale. Every sentence edit triggers a before/edit/after weld check on surrounding sentences.
- **Paragraph level:** Every paragraph rewrite triggers a weld check against the paragraphs above and below.
- **Section level:** Every section restructure triggers a weld check against adjacent sections.
- **Document level:** Not primary — defer to Ripple Read for full-document flow.

## Completion Test
A reader encountering the text for the first time would not detect where the edit was made. The before→edit→after sequence reads as if it were written in one sitting.

## Measurable Features
- Tone consistency across before/edit/after: consistent/inconsistent
- Concept continuity (no unexplained jumps): yes/no
- Register stability (no sudden formality/informality shifts): yes/no
- Direction coherence (text continues moving the same way): yes/no
- Seam detectability (EVALUATOR-AGENT FEATURE — editor agent flags suspected seams, evaluator agent confirms/rejects on a clean read): none confirmed/seam at [location]
